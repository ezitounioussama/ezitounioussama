### [vite-image-react][vir]

[![npm](https://img.shields.io/npm/v/vite-image-react?style=flat-square&logo=npm&logoColor=white&color=FF2D95&labelColor=1A1B27)][npm]
[![downloads](https://img.shields.io/npm/dm/vite-image-react?style=flat-square&color=6F259F&labelColor=1A1B27)][npm]

</td><td valign="top">

**Content-aware, device-adaptive image optimizer for React.** Works with Vite *and* Next.js.

Auto-converts to AVIF/WebP/JPEG with **SSIM auto-tune**, face detection, SVGO and
device-tier delivery — surpassing `next/image` in perceptual quality at equal or smaller
file sizes. Framework-agnostic, so it drops into any React build pipeline.

`TypeScript` · `Vite` · `Sharp` · `MIT`
